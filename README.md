## Sobre el proyecto

**HealthControl** es una aplicación móvil desarrollada para facilitar la gestión,
organización y seguimiento de información relacionada con la salud personal y
familiar.

El proyecto busca ofrecer una experiencia sencilla y accesible, permitiendo
mantener la información de salud organizada y disponible desde un dispositivo
móvil.

---

## Objetivo

Desarrollar una aplicación móvil que permita a los usuarios gestionar de forma
sencilla y organizada su información de salud, facilitando su consulta y
seguimiento en el día a día.

---

## Funcionalidades

- Gestión de información de salud personal y familiar.
- Organización de información relevante.
- Seguimiento de datos relacionados con la salud.
- Acceso desde dispositivos Android.
- Interfaz sencilla y orientada al usuario.

> Las funcionalidades se encuentran en desarrollo y podrán ampliarse durante
> las siguientes etapas del proyecto.
