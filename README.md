# HealthControl
Health Control - Androides

### 🩺 Tu salud, bajo control

HealthControl es una aplicación móvil enfocada en facilitar el seguimiento
y control de información relacionada con la salud personal y familiar.

## 🎯 Objetivo

Desarrollar una aplicación móvil que permita a los usuarios gestionar
de manera sencilla y organizada su información relacionada con la salud.

## ✨ Funcionalidades

-  Gestión de información de salud
-  Interfaz móvil
-  Seguimiento de información relevante
-  Manejo organizado de los datos
